# Tag Master · 全项目极简 UI 改造

## 设计方向

以 ChatGPT 式的极简工作区为参考，采用黑白灰、轻边框、克制阴影、简洁线性图标与清晰文字层级。不复制品牌标识，也不将数据集工具强行改成聊天页面。

本轮修改在上一轮综合优化基础上完成，保留图片、项目、API 配置、批量打标与导出能力。没有推送远程仓库。

### 色彩例外

- 红 / 琥珀 / 低饱和绿保留给错误、警告、成功等有意义的状态。
- 实际数据集图片不做强制灰度处理。
- 服务商头像自定义颜色与调色板是用户功能，保留其真实颜色；新建服务商默认头像改为中性灰。
- 大图预览保持深色媒体背景，有意区别于普通浅色弹窗。

## 交互变化

1. 新用户默认浅色；已有用户保存的深色选择保持有效。
2. 不再在启动后强制打开 API 设置，用户可先整理本地数据；开始 AI 任务时仍执行配置检查。
3. 搜索无结果不再引导用户误以为项目没有图片。
4. 导出 JSON 文案明确为每张图片一份含 `tags` 的 sidecar 文件，不再误称单份 Kohya `metadata.json`。
5. 导出等待跟随真实 Promise，不使用模拟延时。
6. 桌面和移动端共用相同业务状态，窄屏布局不修改用户保存的网格列数。
7. 新增界面文本提供中、英、日资源；原项目中仍有固定中英混排业务文案，本轮并非完整翻译工程。

## 工程维护

- `src/index.css` 中的 `--tm-*` 变量是主题单一来源。
- 新按钮使用 `tm-button`，主按钮添加 `tm-button-primary`，危险按钮用 `tm-button-danger`。
- 输入使用 `tm-input`；弹窗使用 `DialogOverlay`，需要确认/命名时调用 `useDialogs()`。
- 新增 `npm run lint:ui` 并纳入 `npm run check`，扫描 34 个界面源码文件，防止重新引入蓝紫装饰色、渐变和浏览器原生提示框。它是风格约束，不是完整视觉测试。
- 新增 `npm run test:ui` Chromium 冒烟脚本及合成测试图片。测试在隔离浏览器环境运行，不修改用户浏览器数据、不调用 AI API。

### 复现

```bash
npm ci
npm run check

# 首次执行浏览器巡检前安装浏览器与系统库
npx playwright install --with-deps chromium

# 终端一
npm run dev

# 终端二：使用默认 http://localhost:5173/
npm run test:ui

# 也可指定已运行的开发服务器
UI_BASE_URL=http://localhost:5173/ npm run test:ui
```

`test:ui` 使用脚本内的中文文案定位，初始配置为新的隔离浏览器，不要求密钥。截图含有合成图片素材，仅用于验证布局，不是内置业务数据。
